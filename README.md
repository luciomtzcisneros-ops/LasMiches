## ¿Cómo ver el catálogo XML?

El archivo `receta.xml` contiene los ingredientes de la receta.
Puedes visualizarlo de dos formas:

1. **Directamente:** haz clic en el enlace "Ver catálogo" de la página,
   o abre el archivo `receta.xml` desde el repositorio de GitHub.
2. **Cargado dinámicamente:** la página carga el XML con JavaScript
   (`fetch` + `DOMParser`) y lo muestra como lista de ingredientes.
